# Security policy

Report a vulnerability privately through GitHub's "Report a
vulnerability" button on this repository's Security tab. Please do not
open a public issue for it. You will get a reply within 7 days.

Scope: the code in this repository. level-2-build/server.py is a
teaching server on the Python standard library with no authentication;
it binds to localhost by default and is not meant to face a network.
No secrets or model weights are stored in the repo.
